# Kế Hoạch Triển Khai: Trang Web Quà Tặng 20/10 (Romantic Garden & Heartfelt Letter)

---

## 1. Tổng Quan Dự Án
- **Mục tiêu:** Xây dựng một trang web quà tặng 20/10 với giao diện nghệ thuật, chuyển động (animation) mượt mà 60fps, mang lại trải nghiệm cảm xúc sâu sắc cho người nhận: từ ngắm nhìn vườn hoa lung linh, mở bức thư tay bí mật đến gửi lời hồi đáp được lưu trữ an toàn trên Supabase.
- **Đối tượng trải nghiệm:** Bạn nữ được theo đuổi (ưu tiên tối ưu hiển thị hoàn hảo trên điện thoại thông minh: iPhone/Android và máy tính).
- **Hosting:** Vercel.

---

## 2. Kiến Trúc & Công Nghệ Lựa Chọn

| Thành phần | Lựa chọn công nghệ | Lý do lựa chọn |
| :--- | :--- | :--- |
| **Nền tảng / Bundler** | **Vite + Vanilla JS / HTML5 / CSS3** | Nhẹ (<150KB), tải tức thì, không bị giật khung hình trên mobile, deploy Vercel cực nhanh |
| **Hiệu ứng đồ họa** | **HTML5 Canvas + CSS 3D Transforms** | Vẽ hoa nở tự nhiên, cánh hoa bay lơ lửng, phong bì mở 3D chân thực mà không tốn dung lượng tải ảnh |
| **Typography** | **Google Fonts (`Dancing Script` / `Caveat` + `Playfair Display`)** | Hỗ trợ tiếng Việt đầy đủ dấu, nét chữ viết tay mềm mại, chân thành |
| **Hiệu ứng chúc mừng**| **`canvas-confetti`** | Bắn pháo hoa trái tim lung linh khi người ấy gửi lời nhắn |
| **Backend & Database** | **Supabase (PostgreSQL + REST Client)** | Miễn phí, realtime, cho phép người dùng ẩn danh gửi lời nhắn qua RLS (Row Level Security) |
| **Nhạc nền (BGM)** | **Web Audio / HTML5 Audio** | Nhạc piano lofi nhẹ nhàng, có nút bật/tắt tinh tế góc màn hình |

## 4. Kế Hoạch Thực Hiện Từng Bước (Implementation Steps)

### Bước 1: Khởi tạo Project & Cấu trúc thư mục
- Khởi tạo project với **Vite** (Vanilla JS).
- Thiết lập cấu trúc thư mục rõ ràng:
  - `src/styles/`: `garden.css`, `letter.css`, `modal.css`, `style.css`.
  - `src/scripts/`: `garden.js` (canvas hoa), `audio.js`, `supabase.js`, `letter.js`.
  - `public/`: Nhạc nền lofi piano, sound effect mở thư (nếu có).
- Cấu hình file biến môi trường `.env` (`VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`).

### Bước 2: Xây dựng Giao diện Vườn hoa nở rộ (0s - 10s)
- Viết canvas engine vẽ vườn hoa nở từ gốc cành đến từng cánh hoa (procedural flower blooming).
- Thêm hiệu ứng hạt ánh sáng (sparkles/fireflies) và cánh hoa hồng/anh đào rơi bồng bềnh.
- Hiển thị dòng chữ chúc mừng 20/10 với typography cổ điển, hiệu ứng ánh sáng phát quang (glow).
- Bổ sung nút Bật/Tắt nhạc nền du dương (tự động phát sau tương tác đầu tiên của người dùng).

### Bước 3: Thiết kế Hiệu ứng Phong bì 3D & Giấy viết thư tay
- Thiết kế phong bì thư phong cách pastel/vintage viền vàng kim bằng CSS 3D.
- Sau 10s (hoặc nhấn nút mở sớm): Hiển thị Toast thông báo dễ thương + phong bì lướt vào trung tâm màn hình với nhịp thở lơ lửng.
- Khi click: Nắp phong bì lật mở 3D, bức thư từ từ kéo lên và mở rộng ra.
- Hiển thị nội dung thư bằng font chữ viết tay tiếng Việt nắn nót (`Dancing Script`).

### Bước 4: Xử lý Logic Tương tác 2 Nút (Có / Không)
- **Nút "Không":**
  - Khi click: Hiện popup mang tone buồn nhẹ nhàng, hụt hẫng đáng yêu:
    > *"Cậu thật sự chọn 'Không' sao? 🥺"*  
    > *"Tớ đã chuẩn bị khu vườn này và bức thư rất lâu chỉ để mong cậu vui trong ngày hôm nay đấy..."*  
  - Kèm nút: *"Tớ suy nghĩ lại rồi nè 💕"* (click vào sẽ đóng popup và dẫn sang mở popup hồi đáp).
- **Nút "Có":**
  - Mở Popup Form Lời Hồi Đáp sang trọng với viền hoa mờ ảo.
  - Form gồm: Ô nhập tin nhắn tâm sự/cảm nghĩ + Tên/Biệt danh (tùy chọn) + Nút "Gửi lời hồi đáp 💌".

### Bước 5: Cấu hình Supabase & Lưu Trữ Dữ Liệu
- Tạo bảng `replies` trên Supabase:
  ```sql
  create table replies (
    id bigint generated by default as identity primary key,
    created_at timestamp with time zone default timezone('utc'::text, now()) not null,
    choice text not null,        -- 'yes' hoặc 'no_then_yes'
    message text,                -- Nội dung lời nhắn của cô ấy
    sender_name text,            -- Tên/biệt danh nếu nhập
    device_info text             -- Thông tin thiết bị/trình duyệt
  );

  -- Bật RLS và cấp quyền Insert cho Public (anon)
  alter table replies enable row level security;
  create policy "Enable insert for all users" on replies for insert with check (true);
  ```
- Kết nối `@supabase/supabase-js`, xử lý gửi dữ liệu an toàn, có spinner loading và xử lý khi mất mạng.
- Khi gửi thành công: Kích hoạt pháo hoa trái tim `canvas-confetti` + Màn hình cảm ơn ấm áp.

### Bước 6: Kiểm thử & Tối ưu Responsive (Mobile & Desktop)
- Kiểm tra toàn diện trên màn hình điện thoại (Safari iOS, Chrome Android) đảm bảo tỷ lệ khung hình không bị vỡ.
- Đảm bảo font chữ tiếng Việt hiển thị sắc nét, không bị lỗi dấu Unicode.
- Kiểm tra độ mượt chuyển động (60fps), tối ưu bộ nhớ canvas.

### Bước 7: Cấu hình Vercel & Triển khai (Deploy)
- Tạo file cấu hình `vercel.json` tối ưu cho Vite build.
- Cung cấp tài liệu hướng dẫn thêm Environment Variables trên Vercel Dashboard.
- Kiểm tra link production sau khi deploy.
