# Phase 5: Tích Hợp Supabase & Hiệu Ứng Pháo Hoa Trái Tim

## 1. Mục Tiêu
Kết nối cơ sở dữ liệu Supabase để ghi nhận lời hồi đáp từ người nhận một cách an toàn và bảo mật; đồng thời kích hoạt hiệu ứng pháo hoa trái tim rực rỡ và hiển thị màn hình cảm ơn trọn vẹn sau khi gửi thành công.

## 2. Danh Sách Công Việc Chi Tiết
- [ ] **5.1. Thiết Lập Schema Trên Supabase:**
  - Hướng dẫn hoặc chạy script SQL tạo bảng `replies`:
    ```sql
    create table if not exists replies (
      id bigint generated by default as identity primary key,
      created_at timestamp with time zone default timezone('utc'::text, now()) not null,
      choice text not null,        -- 'yes', 'no_then_yes', 'no'
      message text,                -- Nội dung lời nhắn
      sender_name text,            -- Tên người gửi
      device_info text             -- Trình duyệt / Thiết bị (User Agent)
    );

    -- Cấu hình Row Level Security (RLS) cho phép insert ẩn danh
    alter table replies enable row level security;
    create policy "Cho phép người dùng gửi phản hồi" on replies
      for insert with check (true);
    ```
- [ ] **5.2. Khởi Tạo Client Supabase (`src/scripts/supabase.js`):**
  - Sử dụng `@supabase/supabase-js` để tạo client an toàn bằng `VITE_SUPABASE_URL` và `VITE_SUPABASE_ANON_KEY`.
  - Viết hàm `saveResponse({ choice, message, senderName })` có xử lý lỗi (try-catch, timeout).
- [ ] **5.3. Xử Lý Trạng Thái Gửi (Submit Handling):**
  - Hiển thị spinner và vô hiệu hóa nút gửi trong lúc đang xử lý (tránh spam click).
  - Bắt lỗi mạng thân thiện nếu mất kết nối.
- [ ] **5.4. Kích Hoạt Hiệu Ứng Chúc Mừng & Pháo Hoa Trái Tim:**
  - Sử dụng `canvas-confetti` tạo mưa trái tim đa sắc màu bung tỏa khắp màn hình.
  - Hiển thị màn hình thành công lãng mạn:
    > *"Lời nhắn của cậu đã bay thẳng đến tim tớ rồi! ❤️"*  
    > *"Cảm ơn cậu vì đã ghé thăm khu vườn nhỏ này. Chúc cậu có một ngày 20/10 thật hạnh phúc và ngập tràn nụ cười nhé!"*

## 3. Tiêu Chí Hoàn Thành (Acceptance Criteria)
1. Dữ liệu tin nhắn gửi thành công và xuất hiện ngay lập tức trong bảng `replies` trên Supabase dashboard.
2. Hiệu ứng pháo hoa trái tim bung nở đẹp mắt mà không làm đơ giật giao diện.
3. Màn hình cảm ơn hiển thị ngọt ngào, tạo cảm xúc kết thúc trọn vẹn.
